# PRJ-0035 AI 맞춤 문제 출제 서비스 — 모바일 산출물

이 폴더는 기존 Python 출제·채점 엔진을 모바일 UX로 확장하기 위한 설계 문서와 컨셉 프로토타입을 보관합니다.

## 포함 문서
- PRJ-0035_UI-설계서_v1.0.docx
- PRJ-0035_기능정의서_v1.0.docx
- PRJ-0035_API-설계서_v1.0.docx
- PRJ-0035_디자인-시스템_v1.0.docx
- 모바일 인터랙티브 프로토타입 디자인 시안용.html

## 기존 엔진 연결
- 문제은행 검증: quizgen.bank.load / check_item
- 취약점 기반 출제: quizgen.select.pick / weak_topics
- 계산 문제 생성: quizgen.param.make
- 보기 셔플 및 문제지: quizgen.render.shuffle_choices / worksheet
- 채점·취약점 기록: quizgen.grade.grade
- AI 후보 문제 검증: quizgen.bank.accept_ai_items

## 범위 고지
현재 저장소는 Python CLI 엔진이며 AI API, 인증, 서버 저장, 모바일 앱은 연결되어 있지 않습니다. HTML은 메뉴 이동과 입력/풀이 흐름을 확인하는 프론트엔드 컨셉 시안입니다. AI 제공자 연결과 API 계층은 후속 구현 항목입니다.
